# Національна система підготовки українського футболіста U-6—U-21

Автономний україномовний інтерактивний документ Національної футбольної моделі: від філософії гри до щоденної практики тренера.

## Запуск

Залежності та збірка не потрібні. Відкрийте [`index.html`](index.html) у сучасному браузері або запустіть локальний сервер:

```bash
cd /home/runner/work/national-football-model/national-football-model
python3 -m http.server 8000
```

Потім перейдіть на `http://localhost:8000`.

## Структура документа

- **Філософія:** місія, ідентичність, ДНК, принципи гри та модель команди.
- **Методологія:** інтерактивні етапи від U-6—U-7 до U-20—U-21, педагогіка, ролі та критерії переходу.
- **Програма:** адаптивні рамки навантаження, періодизація, мікроцикли, вправи, воротарська програма, KPI та чеклісти.

Увесь документ — один переносимий `index.html`: стилі, структуровані дані вікових етапів і JavaScript-інтерактивність містяться всередині, тому він працює без бекенду й зовнішніх залежностей.

## Функції

- інтерактивна карта розвитку, перемикач віку, пошук і фільтр компонентів;
- світла/темна тема зі збереженням вибору в браузері;
- семантична структура, видимий focus і клавіатурно доступні елементи;
- адаптивний макет та режим друку для збереження в PDF;
- застереження щодо навантажень і неофіційного статусу методичної рамки.

## Подальший розвиток

Розширити бібліотеку вправ, додати локальні відеоматеріали та узгодити документ із затвердженими національними медичними, safeguarding і змагальними регламентами.

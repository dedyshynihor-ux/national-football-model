## 📖 Про проєкт

**Національна Футбольна Модель (NFM)** — це стратегічна ініціатива з розробки комплексної платформи для управління та розвитку українського футболу на всіх рівнях.

Проєкт стартує з розробки **детальної документації та стратегії**, а потім переходить до:
- 🌐 Веб-платформи
- 📱 Мобільного додатку
- 📊 Аналітичних інструментів
- 🤝 Екосистеми взаємодії всіх суб'єктів футболу

## 💻 Встановлення

### Вимоги
- Node.js 18+ або Python 3.9+
- Docker & Docker Compose
- Git

### Локальна розробка

\`\`\`bash
# Клонуємо репозиторій
git clone https://github.com/dedyshynihor-ux/national-football-model.git
cd national-football-model

# Встановлюємо залежності (backend)
cd backend
pip install -r requirements.txt

# Встановлюємо залежності (frontend)
cd ../frontend
npm install

# Запускаємо docker-compose
docker-compose up
\`\`\`
